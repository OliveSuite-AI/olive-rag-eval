# Changelog

## 0.1.0 — initial release candidate

- Rust evaluation engine with embedded TurboVec and SQLite storage.
- Dense retrieval, BM25, RRF, cross-encoder, Laya and local LLM reranking.
- Local answer generation and structured LLM judgment with evidence and reports.
- Odia-first draft multilingual fixtures, language scopes and judge calibration.
- Native Python API, command-line interface, type information and offline demo.
- CPython 3.10+ stable-ABI packaging and five-target wheel CI with pip/uv tests.

Release artifacts have been built locally. Publication and remote CI status must
be verified separately; see RELEASING.md.
